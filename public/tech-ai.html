The Anchor · Anthropic IPO Roadshow — The Largest AI IPO Faces the Public Valuation Question

Anthropic beginning its IPO roadshow is the first public test of whether the AI capital cycle has a second act after OpenAI’s $11 billion private raise at $1.25 trillion confirmed Saturday. The valuation question is specific: Anthropic’s last private round valued it at approximately $2 trillion; the roadshow valuation is reportedly closer to $1 trillion — a 50% compression from the peak that the IPO process will either validate or further reset. The Anthropic-OpenAI valuation gap is the AI market’s most important pricing question for public investors. OpenAI occupies the dominant commercial position: ChatGPT enterprise, the largest API market share, and the brand recognition that generates consumer-side revenue. Anthropic occupies the “safer AI” positioning and the enterprise segment where Constitutional AI and trust commitments have converted into contracts. At $1 trillion versus $1.25 trillion, the market is saying those two positions are worth roughly the same. The IPO roadshow will discover whether that assessment holds when institutional investors with public-market accountability price it. Meanwhile, the Claude Code credential exposure — 1,122 public GitHub files with real passwords — is a headline no company wants to generate during its IPO roadshow. The timing is not fatal, but it is not the story Anthropic would have written.

Claude Code 1122 Public GitHub Settings Files Real Passwords API Keys Apiiro Security Research Enterprise AI Coding Tool Credential Exposure Security Risk Scale November 8 2026 Claude Code · 1,122 GitHub Files · Real Credentials Exposed Claude Code (Sun Nov 8 2026): 1,122 → public → GitHub → settings → files → real → passwords → API → keys → Apiiro → enterprise → AI → coding → tool → credential → exposure → risk → at scale

Apiiro security researchers published findings showing that 1,122 public GitHub repositories contain Claude Code settings files with real passwords and API keys embedded — the first systematic evidence that enterprise AI coding tool adoption is generating credential exposure risk at a scale that security teams have not yet addressed; the exposed credentials include API keys for cloud services, database connection strings, and authentication tokens that were committed alongside Claude Code project configurations by developers who either did not recognize the files as sensitive or did not follow secure credential management practices; the finding is structurally similar to the credential exposure patterns that emerged in the first waves of Docker Hub, npm package publishing, and GitHub Actions adoption — in each case, the new developer tool created a new surface for sensitive data to be committed publicly before organizational controls caught up with the behavior; Apiiro’s sample of 1,122 exposed files covers only publicly searchable repositories and is likely a lower bound on the total exposure across private repositories and enterprise deployments.

Credential exposure from AI coding tools follows the same adoption-curve pattern as every previous developer tool wave: the tool gets deployed faster than the security controls that should govern it, and the gap between deployment and governance is what Apiiro’s 1,122 count is measuring. The fix is well-understood — secret scanning, pre-commit hooks, and security training — but each new tool creates the same gap before the fix is implemented.

DeepMind AI Agents Two Weaknesses Legacy 1024-bit RSA Encryption Anthropic Non-Public Model Proves 18-Year Quantum Conjecture Three Days Dual-Use AI Security Research November 8 2026 DeepMind: RSA Weaknesses · Anthropic: Quantum Conjecture AI security research (Sun Nov 8 2026): DeepMind → AI → agents → two → weaknesses → 1024-bit → RSA → legacy → Anthropic → non-public → model → proves → quantum → conjecture → 18 → years → three → days

DeepMind’s AI agents independently identified two previously unknown weaknesses in legacy 1024-bit RSA encryption — the standard that remains in use in older infrastructure despite having been recommended for retirement for over a decade — a finding that underscores both AI’s capability for cryptanalysis and the ongoing risk from organizations that have not yet migrated to 2048-bit or higher RSA or to elliptic-curve alternatives; separately, a non-public Anthropic model proved an 18-year-old unresolved quantum computing conjecture in approximately three days of inference, a research finding that Anthropic reported internally before public disclosure and that demonstrates AI’s emerging capability to close long-standing theoretical gaps in adjacent fields; together, the two findings describe AI doing what cryptographers and theoretical computer scientists considered extremely difficult: finding new weaknesses in deployed cryptography and resolving open mathematical problems, both in a compressed timeframe and without specialized domain training beyond general-purpose reasoning.

DeepMind finding RSA weaknesses and Anthropic proving a quantum conjecture are the same phenomenon from different directions: AI reasoning at the mathematical frontier is working. The policy implication is that the dual-use concern — AI breaking cryptography, AI accelerating quantum attacks — is no longer theoretical. It is a research output from this week.

The New York Times investigated US government approvals for Nvidia H200 GPU exports to a Beijing-registered entity called New Matrix, which lists a physical address in the Chinese capital that investigators found to be an empty office with no apparent operations, while its ownership structure includes individuals with reported ties to a fund on the US Entity List of sanctioned parties; the investigation adds to a pattern of export control verification failures in which chips approved for civilian end-use reach military-adjacent or blacklisted entities through intermediary structures that satisfy the documentation requirements without reflecting the actual end-user; H200 GPUs are among the highest-performance AI accelerators currently subject to US export control review, and their arrival in China via approved channels — whether through verification gaps or deliberate circumvention — represents a material failure of the technology containment strategy that the Biden and Trump administrations have both treated as a national security priority; the Commerce Department has not publicly commented on the specific entity.

The H200 export probe is the week’s clearest evidence that AI chip export controls are a documentary system being gamed by entities that understand how to satisfy paperwork requirements without satisfying their intent. Empty offices and blacklisted fund ties are not novel evasion techniques — they are the same structures financial sanctions enforcement has been chasing for decades.
